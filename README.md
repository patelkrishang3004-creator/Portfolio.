# Personal Portfolio Website

A simple, responsive portfolio website built with HTML, CSS and JavaScript.

## Features
- Responsive design (works on mobile and desktop)
- Dark mode toggle (choice is saved in the browser)
- Typing animation in the hero section
- Animated skill bars
- Project cards with hover effect
- Contact form with JavaScript validation

## How to run
1. Download or clone this project.
2. Open `index.html` in any browser.

## Files
- `index.html` – page structure
- `style.css` – design and layout
- `script.js` – interactivity

## How to customize
- Replace `Your Name` in `index.html` with your name.
- Edit the skills, projects and contact sections.
- Put your real project links in the project cards.

## Tech used
HTML5, CSS3, JavaScript (ES6)
